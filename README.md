# A-B-Test-Calculator-Sample-Size

## Описание:
Проект **"A-B-Test-Calculator-Sample-Size"** представляет из себя калькулятор А\В-тестов для расчёта статистической значимости изменениий конверсий.
Интерфейс реализован с помощью библиотеки Streamlit и представлен в виде веб-приложения.

## Возможности:
+ **Гибкость ввода:** возможность вводить как сырые данные (количество посетителей и конверсий), так и напрямую задавать коэффициент конверсии для обеих групп (A и B).
+ **Статистическая строгость:** проведение критерия хи-квадрат ($\chi^2$) для определения статистической значимости.
+ **Обработка нулевой конверсии:** вывод информативных предупреждений, если в какой-либо из групп зафиксировано 0 конверсий. 
+ **P-value и интерпретация:** понятное отображение $p$-value и интерпретация результатов с указанием того, есть ли статистически значимое различие между группами.
+ **Размер эффекта (Lift):** расчет и отображение относительного прироста (lift) — улучшения показателя конверсии в группе B по сравнению с группой A.
+ **Доверительные интервалы:** расчет и отображение 95%-х доверительных интервалов для показателей конверсии обеих групп.
+ **Анализ мощности:** если результаты не достигают статистической значимости, калькулятор рассчитывает количество дополнительных конверсий, необходимый группе B для достижения значимости при мощности теста 80%.
+ **Визуализация:** построение столбчатой диаграммы для наглядного сравнения показателей конверсии и их доверительных интервалов.
+ **Удобный интерфейс:** интуитивно понятный макет с всплывающими подсказками для быстрого усвоения каждой метрики.
+ **Дополнительные метрики:** вывод информации об относительном приросте и доверительных интервалах на отдельной вкладке.

## Для запуска:
1) Скопируйте репозиторий - 
```
git clone https://github.com/KostaMiA/A-B-Test-Calculator-Sample-Size.git
```
2) Установите зависимости - 
```
pip install -r requirements.txt
```
3) Запустите приложение через терминал в данной директории - 
```
streamlit run app.py
```
4) Приложение откроется в вашем браузере, где вы сможете внести данные ваших А\В - тестов и увидеть результаты оценки и их интерпретацию.
